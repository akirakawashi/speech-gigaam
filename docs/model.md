# Папка модели

Служба и Triton читают одну папку в формате стенда `temptest`. Её путь на сервере
задаёт `GIGAAM_MODEL_DIR`; принятое место — `/srv/speech-gigaam/model`, вне репозитория.
Сейчас это копия `benchmark-cache/gigaam-trt` стенда ([развёртывание](deployment.md)).

```
артефакты.json                         описание экспорта: модель, словарь, файлы и SHA256
движок.json                            описание движка: SHA256, версия TensorRT, видеокарта, профиль входа
artifacts/
  v3_e2e_rnnt.yaml                     параметры модели
  v3_e2e_rnnt_decoder.onnx             предсказатель RNN-T  ┐
  v3_e2e_rnnt_joint.onnx               совместная сеть      │ читает служба
  v3_e2e_rnnt_preprocessor.pt          окно и мел-фильтры   │
  v3_e2e_rnnt_tokenizer.model          словарь SentencePiece┘
  v3_e2e_rnnt_encoder.onnx             энкодер для сборки движка; службе не нужен
repository/gigaam_encoder/
  config.pbtxt                         настройки модели в Triton, число копий
  1/model.plan                         движок TensorRT — читает Triton
```

## Проверки при старте

Служба не запускается, если:

- размер или SHA256 частей, которые она читает, не совпадают с `артефакты.json`;
- в параметрах модели не RNN-T или не тот извлекатель признаков;
- в `движок.json` нет профиля входа энкодера; из него берутся пределы фрагмента
  (на стенде — от 0,16 до 32 с);
- SHA256 `model.plan` не совпадает с `движок.json` (при `GIGAAM_VERIFY_ENGINE=true`);
- размер словаря не равен номеру пустого символа модели.

Каждый обработчик дополнительно сверяет модель в самом Triton: TensorRT на
видеокарте, без батчей, входы `audio_signal` FP32 `[1, 64, -1]` и `length` INT64 `[1]`.

## Когда пересобирать движок

Движок TensorRT собирается под конкретную видеокарту, драйвер и версию TensorRT
(версия зашита в образ Triton). Пересборка нужна при смене любого из трёх. Сейчас
это делает стенд: `bash benchmark/run-gigaam-trt.sh …` в `temptest` экспортирует веса
в ONNX и собирает движок в образе Triton, а при совпадении всех трёх использует
готовый. Папка `benchmark-cache/gigaam-trt` на сервере собрана под H100 NVL. После
пересборки её снова копируют в `/srv/speech-gigaam/model` и перезапускают службу:
`docker compose restart`.

Перенос экспорта и сборки движка в сам проект — следующий шаг: тогда проект перестанет
зависеть от стенда.

Окно и мел-фильтры признаков берутся из весов обученной модели
(`*_preprocessor.pt`). Созданные заново, они дают другой текст примерно в четверти
фрагментов — это найдено на стенде; поэтому файл обязателен.
