# Разработка speech-gigaam

## Окружение

```bash
cd speech-gigaam
uv sync --locked          # окружение .venv; PyTorch — CPU-сборка с download.pytorch.org
```

## Проверки

```bash
uv run --locked ruff format --check src tests tools
uv run --locked ruff check src tests tools
uv run --locked mypy src tests tools
uv run --locked pytest -q
GIGAAM_TEST_MODEL_DIR=<папка модели> uv run --locked pytest -q   # ещё и признаки из весов
docker build -t speech-gigaam:0.1.0 .                            # сборка образа
```

Модульные тесты не требуют видеокарты и Triton: сценарий проверяется с поддельными
частями, пул — с поддельным движком в настоящих процессах, HTTP — с поддельной
службой, декодер звука — на сгенерированных WAV.

## Сверка со стендом

Главный критерий правильности: на тех же записях и том же движке служба отдаёт тот же
текст, что стенд `temptest`. Скрипт отправляет записи прогона стенда в работающую
службу и сравнивает SHA256 декодированного звука, число фрагментов речи и текст:

```bash
python3 tools/compare_with_stand.py --url http://127.0.0.1:8090 \
    --stand-run <temptest>/benchmark-results/<прогон gigaam-trt-…> \
    --audio-dir <папка записей этого прогона> --limit 200
```

Скрипту нужен только Python 3. Тексты берутся из `записи/NNNN/gigaam_trt.txt`, а если
их нет — из `отчёт.md` прогона. Код возврата 0 — всё совпало.

Ожидаемый результат на сервере с тем же движком, что у прогона стенда: звук, число
фрагментов и текст совпадают во всех записях.

### Что проверено локально 14.10.2026

Без видеокарты: энкодер считался через ONNX Runtime на процессоре в полной точности,
остальная цепочка — код службы, через настоящий HTTP и пул процессов. Сравнение с
прогоном стенда на RTX 4070 SUPER (`gigaam-trt-20261012-163709-324263`, TensorRT fp16):

- звук совпал байт в байт на всех 100 записях;
- на 12 записях совпали число фрагментов, границы каждой реплики и паузы до мс;
- таймкоды слов совпали, кроме единичных сдвигов ровно на один кадр энкодера (40 мс) —
  там, где энкодер на процессоре дал чуть другой выход;
- текст совпал полностью в 7 из 12 записей; из 4 479 слов отличаются 7, в местах,
  где модель и так сомневается («Фёдор/Игорь Васильевич», «не открываю/не в Крыму»).
  Причина — энкодер на процессоре в полной точности вместо TensorRT fp16; на стенде
  TensorRT и PyTorch так же расходились в 23 словах из 19 957.

Сверку с настоящим Triton запускает владелец.

## Нагрузка

```bash
python3 tools/load_test.py --url http://127.0.0.1:8090 --audio-dir <папка> \
    --concurrency 10 --limit 1000
```

Шлёт файлы параллельно, на 503 ждёт `Retry-After` и повторяет. Итог: время по часам,
часы звука, во сколько раз быстрее реального времени и записей за 15 минут.
Подбирайте `GIGAAM_WORKERS` и `GIGAAM_CPUS` по этому числу; `--concurrency` держите
равным `GIGAAM_WORKERS`.
