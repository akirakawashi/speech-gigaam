# speech-gigaam

Служба распознавания речи GigaAM v3 (`v3_e2e_rnnt`) для GPU-сервера. Принимает файл
записи по HTTP и возвращает реплики с таймкодами, словами, паузами и громкостью каналов.

Устроена как на стенде `temptest`, где этот путь проверен на 3 878 записях:
энкодер GigaAM работает в Triton через TensorRT на видеокарте, а поиск речи,
признаки и декодер — в службе на процессоре. В отличие от стенда, модели
загружаются один раз при старте, и записи обрабатываются параллельно.

```
воркер ──HTTP──► speech-gigaam (процессор) ──gRPC──► Triton (видеокарта)
                  N обработчиков:                    энкодер GigaAM, TensorRT
                  звук → поиск речи → признаки
                  → энкодер → декодер → реплики
```

## Быстрый запуск на сервере

```bash
cp .env.example .env        # указать GIGAAM_MODEL_DIR и число обработчиков
docker compose up -d --build
curl -s http://127.0.0.1:8090/ready
curl -s --data-binary @call.mp3 -H 'Content-Type: application/octet-stream' \
     http://127.0.0.1:8090/v1/transcriptions
```

Образ Triton на сервер переносится вручную: compose его не скачивает. Папка модели
берётся у стенда. Подробно — в [развёртывании](docs/deployment.md).
